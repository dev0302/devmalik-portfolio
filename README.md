# My Portfolio

A personal portfolio website built with Next.js showcasing
my work, skills, and experience as a developer.

## 🌟 Features

- 👤 About Me — personal info, image, and social links
- 🛠️ Tools & Technologies — tech stack I work with
- 💼 Experience Section — my work and learning journey
- 🚀 Projects Section — all my major projects
- ✅ Proof of Work — real work evidence
- 📊 GitHub Contribution Graph — live GitHub activity
- 📄 Resume — viewable and downloadable
- 🔍 Search Option — easily search through content
- 🌙 Dark / Light Theme Toggle
- 📬 Contact Section — reach me directly
- 🔗 Social Links — GitHub, LinkedIn, Twitter/X, Email

## 🛠️ Tech Stack

- **Framework** — Next.js
- **Styling** — Tailwind CSS
- **Deployment** — Vercel (or whatever you used)
